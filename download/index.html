It tells you when there is a newer one

Surfex asks GitHub once at startup whether a newer release exists and puts a badge in the toolbar. Settings → About has the release notes and the button.

Updates are verified before they install

Every bundle is checked against a cryptographic signing key, ensuring you only run authentic and untampered builds.

Your library survives an update

Watch state, favourites, watchlist and settings live safely in local storage, which installing updates will never overwrite.

Rather build it yourself?
